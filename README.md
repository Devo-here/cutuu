# Love Animation

A romantic animated love-letter experience built with React, Vite, and the Web Audio API.

## Features

- Interactive envelope-opening intro
- Customizable animated slides and heart message presets
- Background music and sound effects
- Full-screen cinematic presentation mode
- Export-ready video canvas workflow

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- Motion
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

### Build

```bash
npm run build
```

## Project Structure

- src/ – application source code
- src/components/ – UI and canvas components
- src/utils/ – audio and animation helpers
- assets/ – static assets
